# pjsk-jp

『プロジェクトセカイ カラフルステージ！ feat. 初音ミク』を題材にした **SillyTavern 用キャラクターカード（日本語ユーザー向け版）** です。

## 収録内容

| 種別 | ファイル | 説明 |
| --- | --- | --- |
| キャラクターカード | `characters/pjsk-jp.png` | 初音ミクたち Virtual Singer と各ユニットのメンバーが登場するロールプレイカード（MVU ステータスバー対応） |
| ワールドブック | `worlds/pjsk-jp.json` | 世界観・キャラクター設定・イベント（421 エントリ）。各エントリの**トリガーキーワードを日本語化**（本文は原作のまま） |
| プリセット | `OpenAI Settings/Oneself-jp.json` | 「明月秋青by oneself」のコピー（内容は原版のまま） |

## 使い方

1. SillyTavern を開き、`characters/pjsk-jp.png` をインポートします。
2. ワールドブック `worlds/pjsk-jp.json` をインポートします（カードの `extensions.world` は `pjsk-jp` を参照）。
3. `OpenAI Settings/Oneself-jp.json` をプリセットとして読み込みます。
4. カードの MVU ステータスバー（`<UpdateVariable>` タグを置換）と Tavern Helper スクリプトを有効にすると、時間・場面・好感度・内心などの状態表示（日本語 UI）が動作します。

## 日本語化の範囲

- **カード**：オープニング画面（開場白）テンプレート、8 つのローカル正規表現（MVU ステータスバー UI 含む）、Tavern Helper ボタン類を日本語化。キャラクター名は公式日本語表記（初音ミク、鏡音リン、朝比奈まふゆ 等）に統一。
- **ワールドブック**：各エントリの主要キーワード（トリガー）を日本語化。エントリ本文・コメントは原作のまま。
- **プリセット**：原版（中文）のまま。出力言語などはご自身の環境に合わせて調整してください。
