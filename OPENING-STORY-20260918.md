# Opening story shortcut

The home opening now has a sixth option: **開幕6：下のステータスバーからストーリーを選ぶ**. It scrolls to the status panel in the same message and opens the existing story selector. Repeated clicks keep the selector open. This shortcut does not send a message or start a model request.

The original five greeting options, story catalog, worldbook, variables, and runtime dependencies are unchanged. The UI remains embedded in the opening regex; dependencies remain pinned to v2026.09.17.1. The public card preserves its existing preset packaging.

Both chara and ccv3 PNG payloads are updated together. Desktop and mobile interaction checks cover widths 1440, 390, and 320, delayed panel creation, repeated clicks, selection within the same message, and the original five greeting buttons.
